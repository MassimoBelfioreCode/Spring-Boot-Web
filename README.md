# Spring-Boot-Web

## How to start creating CRUD Web App in Java using Spring-Boot

# ⚙️Spring-Boot project configuration

1. Download and Install VS Code for Linux (if you use a Linux distro). https://code.visualstudio.com/thank-you?dv=linux64&build=stable.

2. Open VS CODE and install the recommended extensions for Spring-Boot and **Java 17** or higher:

* Spring Boot Dashboard

* Spring Boot Tools - by VMWare

* Spring Initializr Java Support - by Microsoft

* Spring Boot Snippets

* Maven for Java - by Microsoft

* Language Support for Java (TM) by Red Hat

* REST client (useful)

* Java Code Generators (useful)

* MySQL (useful)

# 🧙️Create your first App

**go to -> https://start.spring.io/**

Recommended Steps: Project: select Maven, Language: select Java, Spring Boot: select v4.1.2, Project Metadata: for artifact enter the project name, and for the rest use the default recommended choices.

Click now on App Dependancies and select **Spring Web**, then click OK.

**Click now on GENERATE button for creating your project** 🙂️

n.b. Make sure that **maven** is correctely installed in your system, because it is necessary. If not: https://maven.apache.org/

# 🔨️Build and Execute your project

Move inside your project Directory and execute this command: **mvn spring-boot: run**
